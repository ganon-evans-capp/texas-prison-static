## Description

The state of Texas has a robust data reporting system, which includes monthly reports on every inmate in the state prison system. In exploring this data and some of the current policy issues facing Texas prisons, I decided to focus on the aging population in the prisons relative to systematic understaffing and cooling issues amid sweltering summers.

The notebook "analysis.ipynb" uses all of the data in the data folder to produce graphs and images found in graphs.
